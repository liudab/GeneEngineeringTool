# 物种基因数据库插件 — 用户使用指南

## 功能简介

物种基因数据库插件为 HelixCraft 的基因序列数据库模块提供物种特异性的注释数据增强。安装插件后，在基因详情页面可以看到来自多个数据库的注释信息，帮助您更全面地了解基因功能。

## 插件类型

HelixCraft 支持三种插件类型，满足不同使用场景：

### 预存数据型（offline）

- **特点**：插件包内捆绑 CSV 等数据文件，安装时一次性导入本地数据库
- **优点**：数据访问快速、无需网络连接、数据版本稳定
- **适用**：稳定的、不频繁更新的注释数据
- **示例**：水稻插件（`species-rice`）—— 包含 RAP-DB 和 MSU 的 10 万+ 条注释记录

### 在线获取型（online）

- **特点**：插件不包含预存数据，通过互联网 API 或网页实时获取数据
- **优点**：数据始终最新、无需预存大量数据、支持动态数据源
- **适用**：需要实时获取最新数据、数据量巨大无法预存的场景
- **注意**：需要网络连接、数据加载可能有延迟、受 API 限速影响

### 混合型（hybrid）

- **特点**：同时包含预存数据和在线获取能力
- **优点**：预存基础数据保证基本功能，在线获取补充最新信息
- **适用**：既有稳定基础数据、又需要定期更新的场景
- **示例**：预存 RAP-DB 注释 + 在线获取 Ensembl 最新注释

> **提示**：插件卡片上会显示插件类型标识，帮助您了解数据来源方式。

## 安装插件

### 从 .plugin 文件安装

1. 获取 `.plugin` 插件文件（例如 `species-水稻-v1.0.0.plugin`）
2. 打开 HelixCraft
3. 点击左侧导航栏的 **设置**（齿轮图标）
4. 滚动到 **物种数据插件** 区域
5. 点击右上角的 **安装插件** 按钮
6. 在弹出的文件选择对话框中，选择 `.plugin` 文件
7. 等待安装和数据自动导入完成（大文件可能需要几十秒）
8. 安装完成后会自动导入 CSV 数据，并显示导入的注释数量和已匹配数量

> **提示**：`.plugin` 文件是一种特殊的压缩包格式，包含了插件的所有文件和数据。您可以将 `.plugin` 文件分享给其他用户，他们可以直接安装使用。

## 导入数据

安装插件时，CSV 数据会**自动导入**，无需手动操作。安装完成后即可在基因详情页面看到注释标签。

如果您需要**重新导入**数据（例如 CSV 数据已更新），可以使用插件卡片上的 **导入数据** 按钮。

> **提示**：如果安装时还没有导入对应的基因（通过 NCBI 导入），注释数据会保存但不会立即匹配。后续导入基因时会自动匹配。

## 查看基因注释

### 标签页切换

当您选中一个基因，且该基因有物种注释数据时，右侧详情面板顶部会出现标签栏：

```
[NCBI] [RAP-DB (Os05g0333200)] [MSU (LOC_Os05g26890)]
```

- **NCBI**：显示从 NCBI 导入的基因信息（始终可见）
- **RAP-DB / MSU**：显示来自插件数据源的注释信息

### 注释内容

每个数据源标签页包含：

1. **标识符信息**：数据源名称、存取号、NCBI Gene ID、基因符号
2. **外部链接**：点击可跳转到对应数据库的在线页面
3. **基因注释**：根据插件配置的字段显示注释信息
   - 普通文本：单行显示
   - 标签组：分号分隔的多个标签
   - 长文本：保留格式，可滚动查看

## 管理插件

### 启用/禁用插件

- 点击插件卡片右上角的 **已启用/已禁用** 按钮切换状态
- 禁用后，该插件的注释数据不会显示在基因详情中，但数据保留
- 重新启用后立即恢复显示

### 导出插件

1. 在插件卡片上，点击 **导出 .plugin** 按钮
2. 选择保存位置和文件名（默认为 `species-<物种名>-v<版本号>.plugin`）
3. 插件会被打包为单个 `.plugin` 文件
4. 导出的 `.plugin` 文件可以直接传递给其他用户安装使用

### 卸载插件

1. 在插件卡片上，点击 **卸载** 按钮
2. 确认卸载操作
3. 插件及其所有注释数据将被删除

> **注意**：卸载会删除所有关联的注释数据。建议先导出 .plugin 文件备份再卸载。

## NCBI 导入自动匹配

当您通过 NCBI Gene ID 导入基因时：

1. 系统自动检查所有启用的物种插件
2. 如果该 Gene ID 在插件数据中存在对应的注释记录
3. 注释记录会自动关联到新导入的基因
4. 右侧详情面板立即显示对应的数据源标签

这意味着：**先安装插件并导入数据，再导入基因**，可以获得最完整的注释信息。

## 水稻插件数据说明

当前水稻插件（`species-rice`）包含以下数据源：

### RAP-DB
- **来源**：RAP-DB（Rice Annotation Project Database）
- **标识符格式**：`Os01g0100100`
- **注释字段**：基因名称、基因符号、cDNA、RefSeq、UniProt、基本信息、突变体表型、生物学功能

### MSU
- **来源**：MSU Rice Genome Annotation Project
- **标识符格式**：`LOC_Os01g01010`
- **注释字段**：基因名称、基因符号

### 外部链接
- RAP-DB → rapdb.dna.affrc.go.jp
- MSU → rice.uga.org
- NCBI Gene → ncbi.nlm.nih.gov/gene

## 常见问题

### Q: 导入数据后，选中基因但没有显示物种标签？
A: 请检查：
1. 插件是否已启用（设置页面查看）
2. 该基因是否有 NCBI Gene ID
3. 插件数据中是否包含该 Gene ID 的注释记录

### Q: 导入数据很慢？
A: 大型 CSV 文件（如 247K 行）需要一定时间解析和导入。导入过程会显示进度，请耐心等待。

### Q: 如何更新插件数据？
A: 
1. 先卸载旧版本插件
2. 安装新版本插件
3. 重新导入数据

### Q: 导出的 .plugin 文件包含什么？
A: `.plugin` 文件包含完整的插件目录（plugin.json、package.json、data/ 目录等）。不包含数据库中的注释数据，安装后会自动重新导入数据。

### Q: 在线获取型插件使用时需要注意什么？
A:
1. 需要保持网络连接
2. 数据加载可能有一定延迟（取决于 API 响应速度）
3. 部分 API 有请求频率限制，系统会自动限速
4. 在线获取的数据会被缓存，后续访问使用缓存数据
5. 如果缓存过期，系统会自动重新获取

### Q: 如何强制刷新在线获取的缓存数据？
A: 在基因详情面板中，点击在线数据标签页右上角的“刷新”按钮（如果可用），即可强制重新从在线源获取数据。

### Q: 混合型插件的在线部分加载失败会影响预存数据吗？
A: 不会。预存数据和在线获取数据是独立的。即使在线获取失败，预存数据仍然正常显示。在线标签页会显示错误提示，但不会影响其他标签页。
